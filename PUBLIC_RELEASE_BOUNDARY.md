# Public release boundary

This publication-only candidate deliberately excludes all fieldwork and
traditional-knowledge material. It contains only the frozen temporal benchmark,
derived computational outputs, and code required to inspect or reproduce the
methodological results reported in the accompanying manuscript.

Before changing repository visibility or minting a DOI, the accountable authors
must confirm that (1) they hold rights to release each included file under the
selected licence, (2) no restricted material or personal data remain, (3) the
repository URL, release tag, and DOI are final, and (4) all manuscript
declarations match the released artefacts.

The release must remain distinct from any future preparation, exposure, or
causal-validation study.

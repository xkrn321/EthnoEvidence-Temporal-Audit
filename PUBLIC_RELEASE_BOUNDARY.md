# Public release boundary

This publication-only candidate deliberately excludes all fieldwork and
traditional-knowledge material. It contains the frozen temporal benchmark,
derived computational outputs, the exploratory structure-matched transfer-audit
summaries, and code required to inspect or reproduce the methodological results
reported in the accompanying manuscript.

The transfer-audit folder contains derived, non-identifying summaries for 40
additional structure-matched tasks and a pooled post hoc context analysis. It
does not contain the licensed raw DrugCentral tables, local retrieval caches, or
any fieldwork records. These summaries are exploratory workflow-transfer
evidence, not an independent predictive-accuracy benchmark.

The repository is public under the MIT License. Before minting its archival
DOI, the accountable authors must confirm that (1) they hold rights to release
each included file under that licence, (2) no restricted material or personal
data remain, (3) the final DOI creators and repository release tag are correct,
and (4) all manuscript declarations match the released artefacts.

The release must remain distinct from any future preparation, exposure, or
causal-validation study. A later archival release must preserve this boundary
unless the accountable authors complete a new rights and ethics review.
